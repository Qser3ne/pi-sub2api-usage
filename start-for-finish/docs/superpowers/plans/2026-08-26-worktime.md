# worktime 扩展实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个 Pi 扩展，统计当前会话中模型的实际工作时长（仅 agent 运行期），通过 `/worktime` 命令查询，累计值持久化到会话文件。

**Architecture:** 单文件 TypeScript 扩展 `worktime.ts`。核心是两段式计时器（`agent_start` 记起点，`agent_settled` 结算累加），每次结算后用 `pi.appendEntry("worktime", { totalMs })` 持久化；`session_start` 时从会话条目恢复累计值，`session_shutdown` 兜底结算未完成段。纯逻辑（计时器、格式化）与 pi 事件接线分离，纯逻辑用 Node 内置 test runner 做单元测试。

**Tech Stack:** TypeScript（经 jiti 直接加载，无需编译产物）、Node.js 内置 `node:test` + `--experimental-strip-types`、devDependencies 仅用于类型检查（typescript、@earendil-works/pi-coding-agent、@types/node）。

**Spec:** docs/superpowers/specs/2026-08-26-worktime-design.md

## Global Constraints

- 运行时零 npm 依赖：`worktime.ts` 对 `@earendil-works/pi-coding-agent` 只允许 `import type`（运行时会被剥离），保证该文件可单独拷贝到 `~/.pi/agent/extensions/` 使用。
- 自定义会话条目：`customType = "worktime"`，data 形如 `{ totalMs: number }`；加载时取最后一条。
- 「工作」定义 = 整个 agent 运行期（`agent_start` → `agent_settled`），含工具执行、自动重试、压缩重试；空闲不计时。
- 展示方式仅为 `/worktime` 命令 + `ctx.ui.notify`，不使用状态栏 / widget。
- 所有持久化写入必须 try/catch 包裹，失败时 notify 警告但不抛出。
- 测试命令：`npm test`；类型检查命令：`npm run typecheck`。两者都必须通过才能提交。

```typescript
/**
 * worktime — 统计当前会话中模型的工作时长。
 * 只累计 agent 运行期（agent_start → agent_settled），空闲不计时。
 * 通过 /worktime 命令查询；累计值持久化到会话条目，resume 后延续。
 */

/** 把毫秒格式化为「X小时Y分Z秒」。 */
export function formatDuration(ms: number): string {
  const totalSec = Math.floor(Math.max(0, ms) / 1000);
  const h = Math.floor(totalSec / 3600);
  const m = Math.floor((totalSec % 3600) / 60);
  const s = totalSec % 60;
  const parts: string[] = [];
  if (h > 0) parts.push(`${h}小时`);
  if (h > 0 || m > 0) parts.push(`${m}分`);
  parts.push(`${s}秒`);
  return parts.join("");
}
```

### Task 2: WorktimeTracker 计时状态机

**Files:**
- Modify: `worktime.ts`（追加 createWorktimeTracker）
- Test: `tests/tracker.test.ts`

**Interfaces:**
- Consumes: 无（依赖注入时钟）
- Produces:
  - `createWorktimeTracker(now?: () => number): WorktimeTracker`，返回对象的方法与访问器：
    - `reset(restoredTotal?: number): void` — 清零并把 `totalMs` 设为恢复值，结束进行中的段
    - `start(): void` — 开始一段计时；若上一段未结算先自动结算（防重叠）
    - `settle(): boolean` — 结束当前段并累加；有段被结算返回 `true`，本来就在空闲则返回 `false`
    - `get totalMs(): number`
    - `get isRunning(): boolean`
    - `currentRunMs(): number` — 当前段的实时时长，空闲时为 0
  - Task 3 的扩展接线将直接消费这些签名。

```typescript
export function createWorktimeTracker(now: () => number = Date.now) {
  let totalMs = 0;
  let runStartTs: number | null = null;

  const settle = (): boolean => {
    if (runStartTs === null) return false;
    totalMs += Math.max(0, now() - runStartTs);
    runStartTs = null;
    return true;
  };

  return {
    reset(restoredTotal = 0): void {
      totalMs = restoredTotal;
      runStartTs = null;
    },
    start(): void {
      settle(); // 防重叠：上一段未结算先结算
      runStartTs = now();
    },
    settle,
    get totalMs(): number {
      return totalMs;
    },
    get isRunning(): boolean {
      return runStartTs !== null;
    },
    currentRunMs(): number {
      return runStartTs === null ? 0 : Math.max(0, now() - runStartTs);
    },
  };
}

export type WorktimeTracker = ReturnType<typeof createWorktimeTracker>;
```

```typescript
/** 从会话条目中找最后一条 worktime 条目，返回其 totalMs；没有则返回 0。 */
function findPersistedTotal(entries: ReadonlyArray<{ type: string; customType?: string; data?: unknown }>): number {
  for (let i = entries.length - 1; i >= 0; i--) {
    const e = entries[i];
    if (e.type === "custom" && e.customType === ENTRY_TYPE) {
      const d = e.data as { totalMs?: unknown } | undefined;
      if (typeof d?.totalMs === "number") return d.totalMs;
    }
  }
  return 0;
}
```

- [ ] **Step 3: 追加默认导出工厂函数**

在文件末尾追加：

```typescript
export default function worktime(pi: ExtensionAPI) {
  const tracker = createWorktimeTracker();

  // 持久化当前累计值；失败只警告，不影响使用。
  const persist = (ctx: ExtensionContext): void => {
    try {
      pi.appendEntry(ENTRY_TYPE, { totalMs: tracker.totalMs });
    } catch (err) {
      try {
        ctx.ui.notify(`[worktime] 持久化失败: ${String(err)}`, "error");
      } catch {
        /* notify 本身失败时静默 */
      }
    }
  };

  pi.on("session_start", async (_event, ctx) => {
    tracker.reset(findPersistedTotal(ctx.sessionManager.getEntries()));
  });

  pi.on("agent_start", async () => {
    tracker.start();
  });

  pi.on("agent_settled", async (_event, ctx) => {
    if (tracker.settle()) persist(ctx);
  });

  // 兜底：任务中途退出（quit/reload/new/resume/fork）也把未结算段写入。
  pi.on("session_shutdown", async (_event, ctx) => {
    if (tracker.settle()) persist(ctx);
  });

  pi.registerCommand("worktime", {
    description: "查看本会话模型工作时长",
    handler: async (_args, ctx) => {
      const lines: string[] = [];
      if (tracker.totalMs > 0 || tracker.isRunning) {
        lines.push(`⏱ 本会话模型工作时长: ${formatDuration(tracker.totalMs)}`);
      } else {
        lines.push("⏱ 本会话还没有模型工作记录");
      }
      if (tracker.isRunning) {
        lines.push(`   当前已连续工作 ${formatDuration(tracker.currentRunMs())}`);
      }
      ctx.ui.notify(lines.join("\n"), "info");
    },
  });
}
```
